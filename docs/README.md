# Devoirly Privacy — GitHub Pages

Ce dépôt contient la page publique de politique de confidentialité de Devoirly.

## Publication avec GitHub Pages

1. Sur GitHub, créez un dépôt public nommé `devoirly-privacy`.
2. Ajoutez `index.html` et ce `README.md` à la racine du dépôt.
3. Ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche **main** et le dossier **/(root)**, puis **Save**.
6. Après quelques minutes, la page sera disponible à :

   `https://VOTRE-NOM-GITHUB.github.io/devoirly-privacy/`

7. Copiez cette URL dans le champ **URL des règles de confidentialité** du Chrome Web Store.

## Mise à jour

Si le comportement de l’extension change (nouvelle donnée lue, nouveau service tiers, nouveau serveur, publicité, analytique, etc.), mettez à jour `index.html` avant de publier la nouvelle version.
